# River Reach Guide

River Reach Guide is a guide to river-reach modeling and routing in SWMM and ICM. It walks through how open-channel reaches are represented in these tools, covering the routing concepts and setup choices that come up when a network segment is a natural or engineered channel rather than a pipe.

The project is built with Vite, TypeScript, React, shadcn-ui, and Tailwind CSS.
